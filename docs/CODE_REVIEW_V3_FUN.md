# 终焉钟城 V2 游戏体验审查报告 —— 「不好玩」

> 审查日期：2026-06-02
> 审查范围：部署版本 150.158.10.10:8080 + 本地代码 aud9338
> 审查重点：音乐/音效、特殊能力方块、游戏反馈与趣味性

---

## 审查结论

**V2 试炼引擎（大厅里的俄罗斯方块）完全是静音、无特效、无特殊方块的"裸方块"。V1 游戏页面虽有部分音效和特殊修饰符，但极度简陋。整个项目没有任何音频文件，玩家体验等同于 1990 年代终端俄罗斯方块，与"终焉钟城"的叙事气质完全不匹配。**

核心问题一句话：**交互反馈缺失——玩家做了任何事几乎都感觉不到"这事发生了"。**

- V2 版本中**完全没有这个功能**

## 🟠 严重缺陷

### G1. 没有幽灵方块预览（Ghost Piece）

**这是俄罗斯方块的基础功能。**

玩家无法看到方块最终落点位置的半透明预览。在高速下落时，只能盲猜方块会落到哪里。

V1 (`app.js`) 和 V2 (`v2-main.js`) **都没有实现幽灵方块。**

---

### G2. V2 试炼用 setInterval 而非 requestAnimationFrame

V2 试炼引擎的核心循环（`v2-main.js` 第442行）：

```javascript
this.tick = setInterval(() => this.drop(), 760);
```

**问题：**
- `setInterval` 不考虑屏幕刷新率，在 144Hz 显示器上画面不平滑
- 浏览器标签页不可见时继续运行，浪费资源
- 无法实现流畅的方块移动动画
- V1 正确使用了 `requestAnimationFrame`，V2 倒退了

---

### G3. 没有消行动画 —— 满行直接消失

这是最影响"爽感"的问题。

当玩家消掉一行（或多行）时，满行**直接从棋盘上被删除**，没有任何过渡动画。没有白闪、没有粒子碎片、没有行溶解效果。消行的视觉反馈为零。

**实际流程：**
1. 方块锁定
2. 扫描满行
3. 直接 `grid.splice()` 删除
4. 播放一个简单的"叮"声
5. 结束

**应该有：**
1. 满行闪烁（白色高亮 → 逐渐透明，200ms）
2. 粒子碎片向两侧飞散
3. 得分数字 `+100` 从消行位置弹出
4. 屏幕微微震动（0.5px，60ms）
5. 音效根据消行数递进（1行叮 → 2行叮当 → 3行叮叮当 → 4行钟声轰鸣）

---

### G4. 没有得分弹出数字

消行时看不到 `+100`、`+300`、`+800` 这样的浮动数字。得分直接加到顶部数字上，玩家感受不到"我刚得了多少分"。

---

### G5. 没有屏幕震动

硬降着陆、消四行、濒死续命、神兽降临——这些关键事件发生时，画面没有任何震动效果。俄罗斯方块的"重量感"很大程度上来自屏幕微震动。

---

### G6. 没有连击（Combo）视觉/音效递进

连续消行的 Combo 系统存在，但：

- Combo 2 和 Combo 8 的视觉完全一样
- Combo 2 和 Combo 8 的音效完全一样
- 没有 Combo 计数器在屏幕上闪烁变大
- 没有"COMBO x5!"的激动人心弹窗

---

### G7. 使用均匀随机而非 7-bag 算法

标准俄罗斯方块使用 7-bag 算法（7种方块各出现一次后重新洗牌），保证公平性。

当前代码使用简单的 `Math.random() * 7` 均匀随机：

```javascript
// app.js
const keys = Object.keys(shapes);
return keys[Math.floor(Math.random() * keys.length)];
```

**后果：** 可能连续出现 4 个 I 或连续 8 次不出 I。玩家会觉得"系统在针对我"。

---

### G8. V1 没有暂存（Hold）功能

现代俄罗斯方块的标准功能——按一个键暂存当前方块、换出之前暂存的方块。

V2 实现了 Hold（`v2-main.js` 第356-367行），但 **V1（游戏页面）没有实现**。V1 是更完整的游戏页面，缺少 Hold 是重大遗漏。

---

### G9. 没有 T-Spin / Back-to-Back 检测

进阶技巧（T-Spin、Back-to-Back）完全没有检测。对高水平玩家来说，游戏深度不够。

---

### G10. 濒死状态只有文字提示，无视觉紧张感

当棋盘堆到近顶部时，系统只显示文字 `"濒死 2"`。**没有：**

- 屏幕边缘没有红色血丝效果
- 没有心跳般的屏幕缩放
- 没有背景色逐渐变红
- 没有音效变化（心跳声、警报声）
- 方块颜色没有变化

---
