# 终焉钟城世界观 V2.0

## 一句话

玩家被"钟渊系统"拉入一座无限十日轮回的时钟城市。在方块试炼中刻下钟痕，在雾区交易所试探规则，在列车汽笛声中寻找十二生肖裁判留下的出口。每一轮十日，都是一次新的审判。

## 世界设定

终焉钟城是一座被巨大钟楼统治的环形都市。城市的圆心是十层高的"钟楼"，每一层对应十日轮回中的一天，第十层为"终焉之层"——据说从来没有人真正上去过。

城市围绕着钟楼分为四个区域：
- **东区**：方块试炼场。试炼者在这里用方块刻下钟痕。消行不是游戏，是与时间正面对抗的唯一方式。
- **南区**：雾区交易所。每日午夜，终焉列车运来新一批"雾区商品"——神兽遗物、钟楼零件、规则碎片、生肖符咒。试炼者用刻痕买卖。价格波动不是随机的，是钟渊系统在试探你的贪婪和恐惧。
- **西区**：钟城广场。试炼者的社交中枢——广播台、试炼者名录、契约广场、规则之眼都在这里。也是生肖裁判每日现身的地方。
- **北区**：规则之眼。情报卡片的来源地。每天黄昏，新的情报被投递到北区的信箱里。情报有真有假，价格越高的越接近真相。

高架铁轨环绕全城。终焉列车按固定时刻进站/出站。列车不载人，它只运输"可能"——雾区商品、情报卡片、以及钟渊系统的规则变更通知。汽笛声是这座城市唯一可靠的时间信号。

## 势力与阵营

- **试炼者**：玩家。被困于轮回中的觉醒者。目标不是逃出去，而是看清规则、收集生肖印记和神兽印记、在第十天青龙裁决中活下来。
- **钟渊系统**：城市的创造者和管理者。不可见。它通过钟楼发布试炼宣言，通过列车调度规则变更，通过广播传播情绪。它是规则本身。
- **十二生肖裁判**：钟楼每一层的守护灵。每个十日的前十天，按序当值。当日当值的生肖决定规则的偏向——方块速度、雾区波动、契约奖励、情报价格。生肖裁判不是敌人，他们只是在执行钟渊的意志。
- **四象神兽**：第3、5、7、10天分别降临的终极试炼。白虎的PVP淘汰赛、朱雀的涅槃分数赛、玄武的无尽生存、青龙的第十天终局裁决。击败它们（或在它们面前活下来）能获得永久的神兽印记。
- **终焉列车**：秩序载体。它本身没有意识，但城市的一切变化都通过列车触发。晨钟列车发布宣言，午夜列车运来货物，终焉列车宣告一天结束。
- **回响者**：前代幸存者留下的记忆碎片，以NPC的形式存在于广场和广播中。他们保留部分记忆，能给出模糊的提示，但他们的话不总是对的。

## 核心循环

```
晨钟列车 06:00 → 生肖裁判就位 + 试炼宣言
    ↓
方块试炼（全天）→ 消行 → 获得刻痕
    ↓
刻痕消费路径：
  → 雾区交易所（买入/卖出，等待午夜结算）
  → 规则之眼（购买情报，提前得知趋势）
  → 试炼契约（创建/加入三人小队，共享收益）
  → 铭刻升级（永久提升属性）
    ↓
黄昏列车 18:00 → 情报刷新 + 契约锁定
    ↓
午夜列车 23:00 → 雾区强制平仓 + 新商品到站
    ↓
终焉列车 23:55 → 每日结算 + 排名发布
    ↓
第10天：青龙裁决 + 十日周期总榜 + 城市重置
```

## 核心叙事原则

1. **时间就是一切**。钟声、列车汽笛、倒计时。所有事件按固定时刻发生，无一例外。
2. **规则先于行动**。生肖裁判每天改变规则偏向。先看清今天是什么日子，再决定干什么。
3. **代价与选择**。每一笔交易、每一次契约、每一张情报，都在消耗刻痕。刻痕不是无限的。
4. **信息不对称**。情报卡片有真有假。NPC的话不能全信。排行榜是透明的，但趋势不是。
5. **十日为界**。没有永久的优势。第十天结束后，一切重置（但印记、铭刻升级、钟渊之路进度保留）。
6. **收集即力量**。十二生肖印记和四象神兽印记提供永久加成，收集是跨越周期的唯一积累。

## 文案约束

- 所有界面文案使用"试炼者""钟渊系统""刻痕""钟城广播""试炼契约""规则之眼""铭刻之书"等术语。
- 使用"消行"而非"消除行"；使用"刻痕"而非"金币"或"货币"。
- 生肖裁判使用规范化称呼：全称"生肖裁判·鼠"，简称"鼠裁判"或"鼠"。
- 神兽使用全称：白虎、朱雀、玄武、青龙。
- 列车使用全称：晨钟列车、正午列车、黄昏列车、午夜列车、终焉列车。
- NPC对话风格：拆规则、相互试探、反向诱导、审判施压、温柔支撑。不可出现卖萌、网络用语或现代俚语。
- 系统通知使用第三人称客观叙述："试炼者[名]在雾区买入了白虎利齿。"
- 广播事件始终回流到"全城广播"频道，不可只在单一面板出现。
