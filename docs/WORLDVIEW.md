# 极乐交易城世界观

## 一句话

玩家在“极乐交易城”里用俄罗斯方块铸造金币，再把金币投入股票、期货、公会和聊天室，持续对抗庄家 AI 的收割。

## 世界设定

极乐交易城由庄家 AI“柜台”运营。柜台提供方块战场、交易市场、公会广场和广播台，看似给玩家翻盘机会，实际不断用行情、事件和排行榜制造情绪波动。

玩家身份是“方块矿工”。方块战场是金币来源，交易市场是放大器，公会是抱团反抗方式，排行榜是名声系统，聊天室是情绪扩散器。

## 核心循环

```text
方块战场铸币
  -> 股票/期货下注
  -> 赚亏事件进入广播台
  -> 排行榜与公会放大竞争
  -> 玩家回到方块战场继续铸币
```

## 功能定位

- 大厅：世界入口，展示全服事件、庄家池、排行榜、行情和公会状态。
- 方块战场：主要游戏行为，负责手感、得分、属性方块和金币产出。
- 交易市场：情绪放大器，负责股票、期货、庄家控盘和爆仓故事。
- 公会系统：社交组织，负责联合坐庄、公会战、公会 BOSS。
- 排行榜：目标与名声，制造每日/每周追逐。
- 极乐广播台：聊天、NPC、系统事件和嘲讽的统一出口。
- 玩家资产：身份、签到、称号、持仓和成长记录。
- 后台：庄家控制台，实时调参和制造事件。

## 文案约束

- 统一使用“极乐交易城”“庄家柜台”“极乐广播台”“方块矿工”等词。
- 金币只作为游戏内虚拟货币，不表达真实赌博或真实投资收益。
- NPC 发言服务于世界氛围：喊单、反向指标、嘲讽、内幕、亏损调侃。
- 系统事件要回流到广播台，避免功能页面各说各话。

## 下一阶段系统拆分

- `player`：账号、身份、资产、签到、称号。
- `tetris`：战场模式、属性方块、PVP 干扰、公会 BOSS 战斗。
- `market`：股票、期货、T+1、强平、庄家控盘。
- `guild`：公会成员、公会仓位、公会战、公会金库。
- `chat`：频道、NPC 行为池、红包、广播事件。
- `ranking`：日榜、周榜、奖励结算。
- `admin`：后台权限、操作日志、危险操作确认。
