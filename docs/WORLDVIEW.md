# 终焉钟城世界观

## 一句话

玩家在“终焉钟城”里用俄罗斯方块铸造金币，再把金币投入股票、期货、公会和聊天室，持续对抗钟渊 AI 的收割。

## 世界设定

终焉钟城由钟渊 AI“柜台”运营。柜台提供方块战场、交易市场、公会广场和广播台，看似给玩家翻盘机会，实际不断用行情、事件和排行榜制造情绪波动。

玩家身份是“试炼者”。玩家通过常规账号注册和登录进入钟城，账号数据由 MySQL 保存。方块战场是金币来源，交易市场是放大器，公会是抱团反抗方式，排行榜是名声系统，聊天室会围绕真实新闻和行情扩散情绪。

## 核心循环

```text
方块战场铸币
  -> 股票/期货下注
  -> 赚亏事件进入广播台
  -> 排行榜与公会放大竞争
  -> 玩家回到方块战场继续铸币
```

## 功能定位

- 大厅：世界入口，展示全服事件、钟渊池、排行榜、行情和公会状态。
- 方块战场：主要游戏行为，负责手感、得分、属性方块、钟渊回溯、昼夜速度、濒死续命和金币产出。
- 交易市场：情绪放大器，负责股票、期货、钟渊控盘和爆仓故事。
- 公会系统：社交组织，负责联合坐庄、公会战、公会 BOSS。
- 活动中心：每日任务、柜台商店和限时事件，负责留存和短期目标。
- 排行榜：目标与名声，制造每日/每周追逐。
- 钟城广播：聊天、NPC、系统事件和嘲讽的统一出口。
- 身份中心：账号注册/登录、签到、称号、持仓和成长记录。
- 真实信息层：股票行情、财经新闻、济南天气、系统时间和版本信息。
- 天道参照：以“看清规律、识别结构、理解因果”为核心的思考卡片，保留丁元英式冷静审视系统的气质。
- 后台：钟渊控制台，实时调参和制造事件。

## 文案约束

- 统一使用“终焉钟城”“钟渊系统”“钟城广播”“试炼者”等词。
- 金币只作为游戏内虚拟货币，不表达真实赌博或真实投资收益。
- NPC 发言服务于世界氛围：喊单、反向指标、嘲讽、内幕、亏损调侃。
- 系统事件要回流到广播台，避免功能页面各说各话。

## 下一阶段系统拆分

- `account`：注册、登录、会话、账号状态。
- `player`：身份档案、资产、签到、称号。
- `external`：真实行情、新闻、天气与系统版本信息。
- `tetris`：战场模式、属性方块、PVP 干扰、公会 BOSS 战斗。
- `market`：股票、期货、T+1、强平、钟渊控盘。
- `guild`：公会成员、公会仓位、公会战、公会金库。
- `activity`：每日任务、商店道具、限时活动。
- `chat`：频道、NPC 行为池、红包、广播事件。
- `ranking`：日榜、周榜、奖励结算。
- `admin`：后台权限、操作日志、危险操作确认。
